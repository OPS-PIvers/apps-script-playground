# Audience: internal / parents-community

| Knob | Setting |
|---|---|
| **Tone** | Warm, welcoming, reassuring. |
| **Reading level / jargon** | **Zero jargon.** Everyday language, as if talking to a neighbor. |
| **Default theme** | Mode 1 (official), **light**. |
| **Density** | Low. Big visuals, one plain idea per slide. |
| **Formality** | Friendly and approachable, not stiff. |
| **`data-motion`** | `calm`-to-`standard`. |
| **QR / poll / badge** | No polls by default. QR welcome for "learn more," sign up, or a contact. |
| **Preferred close** | A warm thank-you and an easy next step (where to go, who to ask). |

## What to assume / emphasize
Frame everything as **"what it means for you / your child."** Lead with
benefits and reassurance, not features or process. Assume no technical
background and no insider context.
