# Audience: internal / students

| Knob | Setting |
|---|---|
| **Tone** | Encouraging, energetic, approachable. |
| **Reading level / jargon** | Simpler language; define any term that isn't everyday. Short sentences. |
| **Default theme** | **Mode 2 latitude** — palette can flex and feel playful; logos stay as-issued. Light or dark both fine; can lean light and bright. |
| **Density** | Low. One idea per slide, big visuals. |
| **Formality** | Casual and warm. |
| **`data-motion`** | `standard`. |
| **QR / poll / badge** | **Polls welcome** — students like to participate. QR fine for handouts/links. |
| **Preferred close** | Upbeat, with a clear "now you try" or "here's where to go next." |

## What to assume / emphasize
Assume curiosity, not prior knowledge. Keep it concrete, show don't tell, and
make participation easy. Playful is allowed and encouraged here.
